# 1 Collection — Coming Soon

Страница «Скоро открытие» портала 1 Collection для GitHub Pages: две
статические языковые версии, без скриптов и сборки.

Оформление повторяет портал: цвета светлой и тёмной темы (`globals.css`
портала), шрифты Geist и Barlow Condensed (логотип), знак-логотип,
кнопки и подвал. Подложка — баннер главной страницы портала. Тема
выбирается по настройке системы (`prefers-color-scheme`).

## Языки

Адреса — как у портала: у русской версии префикса нет, английская живёт
под `/en/`. Это разные страницы со своим адресом, `hreflang` и `canonical`,
поэтому поисковик и превью ссылки видят каждую на её языке. Текст правится
в обоих файлах.

Переключатель в подвале повторяет портальный (`language-switch.tsx`), но
построен на нативном `popover`: Escape, клик мимо и возврат фокуса даёт
браузер. Браузер без CSS anchor positioning покажет список по центру экрана.

Сама страница язык не определяет и выбор не запоминает: `/` всегда открывается
по-русски. У GitHub Pages нет сервера, который мог бы выбрать язык до ответа.

## Состав

| Файл | Что это |
| --- | --- |
| `index.html` | русская версия, адрес `/` |
| `en/index.html` | английская версия, адрес `/en/` |
| `assets/styles.css` | стили обеих версий |
| `assets/flags/` | флаги переключателя языка из набора flag-icons портала и их лицензия MIT |
| `assets/banner.webp`, `assets/banner-narrow.webp` | баннер: широкий кадр и середина снимка для телефона (уже 640 px) |
| `assets/og.png` | превью ссылки в соцсетях и мессенджерах, 1200 × 630 |
| `assets/icon.png`, `favicon.ico` | значок вкладки |
| `assets/fonts/` | шрифты (woff2) и их лицензии SIL OFL 1.1 |
| `.nojekyll` | отдавать файлы как есть, без обработки Jekyll |

Сторонних доменов страница не использует: шрифты и картинки лежат рядом.

## Публикация

Settings → Pages → Source: **Deploy from a branch**, ветка `main`,
папка `/ (root)`. Страница живёт на своём домене —
<https://1collection.app/>: его называет файл `CNAME`, а в настройках
Pages стоит включить **Enforce HTTPS**.

У домена в DNS должны быть записи GitHub Pages: для `1collection.app` —
четыре `A` (`185.199.108.153`, `185.199.109.153`, `185.199.110.153`,
`185.199.111.153`), для `www` — `CNAME` на `1collection.github.io`.

Адрес `https://1collection.app/` записан и в обеих страницах — в `canonical`,
`hreflang`, `og:url` и `og:image`. Сменится домен — менять и `CNAME`, и эти
адреса, иначе превью ссылки возьмёт картинку со старого.

## Проверка локально

Любой статический сервер из корня репозитория, например:

```bash
npx serve .
```
