# 1 Collection — Coming Soon

Страница «Скоро открытие» портала 1 Collection для GitHub Pages: один
статический `index.html`, без скриптов и сборки.

Оформление повторяет портал: цвета светлой и тёмной темы (`globals.css`
портала), шрифты Geist и Barlow Condensed (логотип), знак-логотип,
кнопки и подвал. Подложка — баннер главной страницы портала. Тема
выбирается по настройке системы (`prefers-color-scheme`).

## Состав

| Файл | Что это |
| --- | --- |
| `index.html` | страница целиком, стили внутри |
| `assets/banner.webp`, `assets/banner-narrow.webp` | баннер: широкий кадр и середина снимка для телефона (уже 640 px) |
| `assets/og.png` | превью ссылки в соцсетях и мессенджерах, 1200 × 630 |
| `assets/icon.png`, `favicon.ico` | значок вкладки |
| `assets/fonts/` | шрифты (woff2) и их лицензии SIL OFL 1.1 |
| `.nojekyll` | отдавать файлы как есть, без обработки Jekyll |

Сторонних доменов страница не использует: шрифты и картинки лежат рядом.

## Публикация

Settings → Pages → Source: **Deploy from a branch**, ветка `main`,
папка `/ (root)`. Страница живёт на своём домене —
<https://1collection.app/>: его называет файл `CNAME`, а в настройках
Pages стоит включить **Enforce HTTPS**.

У домена в DNS должны быть записи GitHub Pages: для `1collection.app` —
четыре `A` (`185.199.108.153`, `185.199.109.153`, `185.199.110.153`,
`185.199.111.153`), для `www` — `CNAME` на `1collection.github.io`.

Адрес `https://1collection.app/` записан и в `index.html` — в `canonical`,
`og:url` и `og:image`. Сменится домен — менять и `CNAME`, и эти три адреса,
иначе превью ссылки возьмёт картинку со старого.

## Проверка локально

Любой статический сервер из корня репозитория, например:

```bash
npx serve .
```
